# Hands-On-Assignment-2
Hands-On Assignment 2: Construct AI QR Code Generator with Python
This project demonstrates how to build a simple QR Code generator using Python. By leveraging the qrcode library and Pillow, the script takes a URL as input, generates a QR code with customizable parameters (version, error correction, box size, border), and outputs a PNG image. The generated QR code can be saved locally and displayed directly in a Jupyter Notebook.

Key Features:

Uses qrcode and Pillow libraries

Accepts any URL or text input

Customizable QR code size, border, and error correction level

Saves QR code as an image (qrcode_output.png)

Displays the QR code inline in notebooks
